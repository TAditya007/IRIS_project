Bugs found and fixed during self-testing:
  1. Rician 4th-moment estimator was wrong.
     - Test used (2K+1)/(K+1) — valid only for deterministic LOS.
     - Correct for random per-element LOS phase: (K^2 + 4K + 2)/(K + 1)^2.
     - For K=10, theory = 1.1736, empirical = 1.1708.
  2. Assumed idle users see zero interference.
     - Physical model: RIS reflects everything it receives, so idle users
       see interference from every other user's allocation.
     - Test updated to expect positive interference on idle users.
  3. JFI lower bound test was wrong.
     - Asserted JFI < 0.1 for unequal rates — impossible.
     - Correct lower bound is 1/N = 0.333 for N=3.
     - Test rewritten to check theoretical bounds.

Attempts:

  2. Vanilla DQN + buffer (train.py)        -> JFI = 0.333 collapse
  3. Literal Algorithm 1 (train_alg1.py)    -> JFI = 0.333 collapse
  4. + beta_interference = 1.0              -> JFI = 0.333 collapse
  5. + reward scale = 0.1                   -> JFI = 0.333 collapse
  6. + cancellation pool (N+1 actions)      -> cancel-all attractor
  7. + service bonus theta_serve = 5        -> partial learn, oscillates

CONCLUSION:
  - The literal Algorithm 1 (batch-1, no target net, no buffer) with
    the paper's Eq. 11 reward does not converge on this system model.
  - Cancellation pool makes it worse by introducing a "cancel everything"
    attractor.
  - A per-user service bonus is required to break both degenerate optima.

[PHASE A+] Noise Power Fix
============================================================
Started:  2026-10-05 12:30
Ended:    2026-10-05 14:30
Status:   COMPLETE

Change:
  noise_power_dbm: -90.0  ->  -10.0

Rationale:
  - At -90 dBm, SNR with a single element is already ~1e12.
  - Rate saturates at log2(1e12) ≈ 40 bps/Hz with one element.
  - Additional elements give almost no gain, so no incentive to spread.
  - Setting noise to -10 dBm puts signal and interference in a comparable
    regime, restoring meaningful marginal returns per element.

Effect:
  - Collapse policy sum-rate dropped from 51 to ~25 bps/Hz.
  - Balanced policy sum-rate now ~12 bps/Hz — comparable to reference paper.
  - Reward landscape now differentiates balanced vs. collapse.

[PHASE A++] Soft Path Loss
============================================================
Started:  2026-10-05 14:30
Ended:    2026-10-05 15:00
Status:   COMPLETE

Change:
  - Added bounded path-loss proxy (0-15 dB) driven by per-episode user distances.
  - EnvConfig gains: max_distance_m=100, min_distance_m=10,
    carrier_freq_ghz=2.4, path_loss_alpha=3.0 (proxy only).

Rationale:
  - Reference paper (Section IV) places users at random distances up to 100 m.
  - Physical free-space path loss at 2.4 GHz over 10-100 m reduces SNR to
    near zero with our parameter regime.
  - A bounded proxy preserves the intent (per-episode variability) without
    extinguishing the signal.
  - Documented as Rule R10 assumption.

Effect:
  - Per-episode channel diversity now present.
  - DQN has to adapt its allocation per channel.
